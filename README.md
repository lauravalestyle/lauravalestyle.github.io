# Laura Vale | Style & Travel

Mobile-first landing page for the Laura Vale AI lifestyle/fashion account.

## GitHub Pages

Repository name: `lauravalestyle.github.io`

After uploading these files, enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Fanvue

The Fanvue button is already included as a disabled **“💎 Fanvue — coming soon”** button. When the Fanvue URL is ready, replace that button in `index.html` with:

```html
<a class="cta" href="YOUR_FANVUE_URL" target="_blank" rel="noopener noreferrer">💎 Fanvue</a>
```

No redesign is needed.

## Datify

The approved Threads organic tracking URL is already connected to the main CTA buttons. Keep `aid`, `kid`, and `sub1=threads_organic` intact.
